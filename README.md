# Tabellenrechner

Fußball-Tabellenrechner (Bundesliga bis 5. Liga, DFB-Pokal, CL/EL/ECL) als eine React-Datei.
Details für Entwickler/Agenten: siehe `CLAUDE.md`.

```bash
cd test && npm install && ./build.sh   # erzeugt dist/index.html
```
Die fertige Seite `dist/index.html` lässt sich direkt im Browser öffnen. Der Spielstand liegt im Browser (localStorage).
